How an exam runs

Four steps from an empty question bank to a finished report.

  1. Add questions

    Teachers write questions and file them by subject and difficulty.

  2. Create the exam

    Pick the date, duration, and marks, then choose the questions to include.

  3. Students take it

    Students sign in, answer each question, and submit.

  4. Read the results

    Scores, answer reviews, and class reports are available straight away.

Common questions

Click a question to open the answer.

Which question types are supported?

Multiple choice, true or false, and descriptive questions can be stored in the question bank.

Can students see their answers after the exam?

Yes, if the teacher turns on answer review for that exam. Each answer is shown with the correct one and a short explanation.

Does it work on a phone?

Yes. Every page adjusts to small screens, and the question panel moves above the questions on a phone.

Is this a finished product?

This is a front-end prototype built with HTML and CSS. Sign-in, timing, and automatic grading need a backend and JavaScript, which can be added later.
